# Investigación de Mercado Chiapas - Terrenos y Lotes

Carpeta de trabajo para organizar investigación externa sobre terrenos, lotes residenciales, terrenos campestres y desarrollos inmobiliarios en Chiapas.

## Estructura

- `oficiales/links_oficiales_300_50_50_datos_ventas.txt`: lista prioritaria actualizada de 300 URLs oficiales, una por línea, sin comentarios. Contiene 150 fuentes de datos Chiapas y 150 fuentes oficiales de ventas/marketing digital.
- `oficiales/links_oficiales_300_50_50_datos_ventas.csv`: la misma lista con categoría para filtrar fuentes.
- `oficiales/links_oficiales_300.txt`: respaldo de la primera lista amplia de fuentes oficiales.
- `oficiales/fuentes_clave_por_ciudad.md`: fuentes oficiales priorizadas para las ciudades objetivo.
- `estrategia/ampliacion_investigacion_mercado.md`: marco ampliado de análisis para ventas y Meta Ads.
- `fuentes/metodologia_y_validacion.md`: reglas de evidencia, inferencia e hipótesis.
- `portales/competidores_iniciales.csv`: base inicial de competidores/campañas públicas ya detectadas.

## Regla de trabajo

No usar datos internos del usuario. Separar evidencia comprobada, inferencia razonable e hipótesis estratégica.
