## 1. ¿Qué es Street Boss?
Street Boss es un ecosistema tecnológico integral. Está compuesto por un producto de software avanzado (SaaS/Plataforma) y una marca sólida respaldada por un sistema de marketing, branding y contenido. 
Ambos conviven en armonía y evolucionan de forma coordinada para dominar el mercado.

---

## 2. ¿Qué contiene `streetboss/`? (El Software)
La carpeta `streetboss/` es el **Núcleo Tecnológico**.
Aquí vive **EXCLUSIVAMENTE** el software:
- React y Vite.
- Supabase (Backend/Base de Datos y SQL).
- Landing y Demos.
- Código fuente y Assets utilizados por la aplicación.
- Git, Vercel, Build y Deploy.

*(Aquí vive TODO el software y desarrollo técnico).*

---

## 3. ¿Qué contiene `streetboss-studio/`? (El Centro Creativo)
La carpeta `streetboss-studio/` es el **Núcleo de Marketing e Identidad**.
Toda la identidad visual, el contenido para redes y la estrategia comercial deberá vivir aquí.
Contiene **EXCLUSIVAMENTE**:
- Branding, Manual de marca, Logos, Colores, Tipografías.
- Recursos gráficos e Imágenes.
- Redes sociales y Calendario editorial.
- SEO y Google Business.
- Presentaciones, Documentación comercial y Estrategia.
- Biblioteca multimedia y Videos.
- Campañas.
- Recursos y Prompts para IA.

*(Aquí **NO** debe existir código React, Supabase, package.json ni Git del software).*

---

## 4. ¿Cómo trabajan juntos?
Ambos proyectos son las piezas de un engranaje maestro:
1. **Studio** conceptualiza, diseña, atrae tráfico y genera clientes mediante estrategias visuales, documentación y redes sociales.
2. **Software** recibe la visión y el tráfico, construyendo el producto funcional y la infraestructura web sin estar contaminado por archivos de diseño.

No se mezclan archivos ni se fusionan carpetas. El ecosistema es único, compuesto por estas dos mitades esenciales.
