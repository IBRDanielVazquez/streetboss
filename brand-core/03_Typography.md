# TYPOGRAPHY SYSTEM

*   **Títulos y Destacados (Headings):** `Poppins`
    *   *Peso:* Bold / ExtraBold. (Uso en nombres de restaurantes, precios y slogans).
*   **Cuerpo de Texto y UI (Body/UI):** `Inter`
    *   *Peso:* Regular / Medium. (Uso en descripciones de platillos, botones y menús de navegación).
