# BRAND IDENTITY SYSTEM | STREETBOSS

Este es el directorio matriz (Brand Core). Esta carpeta es la ÚNICA fuente de verdad para la identidad corporativa de StreetBoss.

## Índice del Core
- `01_Master_Logo_Horizontal_Completo` (con Tagline): El Logotipo Principal y Oficial que debe predominar en todas las piezas.
- `01_Master_Icon`: Isotipo (B con flama o App Icon) - Solo para avatares y espacios cuadrados mínimos.
- `02_Color_System.md`: Paleta oficial
- `03_Typography.md`: Sistema de tipografías
- `04_Logo_Clearspace.md`: Reglas de geometría y espaciado
- `05_Brand_Rules.md`: Leyes prohibitivas y autorizadas de IA

> **ADVERTENCIA PARA AGENTES IA:** Todo documento en esta carpeta debe ser leído y respetado antes de generar cualquier activo de la marca. El LOGO COMPLETO debe visualizarse DE MANERA FUERTE Y PREDOMINANTE en todos los materiales gráficos, portadas y banners.
