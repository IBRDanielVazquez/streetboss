# Prompts

## 1. Objetivo
Estandarizar y optimizar las instrucciones dadas a las inteligencias artificiales.

## 2. Alcance
Prompts para generación de texto (ChatGPT/Claude) e imagen (Midjourney).

## 3. Contenido Esperado
- Librería de Prompts estructurados.
- Ejemplos de inputs/outputs exitosos.

## 4. Reglas
- Documentar siempre qué IA se debe usar para cada prompt.
- Mantener formato: Contexto, Instrucción, Tono, Reglas.

## 5. Relación con Street Boss
Acelera dramáticamente la producción de contenido y código de Street Boss.

## 6. Flujo de Trabajo
1. Probar prompt.
2. Refinar resultados.
3. Documentar en la biblioteca.
4. Reutilizar.
