# T06 · FoodPorn

**Propósito:** Fotografía gastronómica premium: el antojo es el mensaje.
**Dimensiones base:** 1080×1920 / 1080×1080

## Layout
1. 80% comida, 20% interfaz.
2. Luz dura moody, fondo oscuro texturizado.
3. Macro/45°, colores saturados del apetito.
4. Titular mínimo; logo pequeño (Icon o Dark).

## Sistema visual (obligatorio)
- Colores: #FF4B00 / #0D0E12 / #FF6A1A / #FFFFFF. Sin degradados/brillos/sombras.
- Tipografía: Poppins (títulos) + Inter (cuerpo).
- Logo: SVG maestro de `brand-core/` (fondo oscuro → `_Dark`). Nunca regenerar.
- Regla 80/20 en piezas con comida.

## Notas
Sin rostros. Vapor/goteo bienvenidos.
