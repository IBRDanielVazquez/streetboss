# T07 · Carrusel Educativo

**Propósito:** Educación multi-slide (6–7 diapositivas) que gana guardados.
**Dimensiones base:** 1080×1350 ×N

## Layout
1. Slide 1 portada con gancho.
2. 1 idea por slide, mucho aire.
3. Datos como CASO ILUSTRATIVO cuando aplique.
4. Slide final = CTA + logo + (opcional) precio fundador.

## Sistema visual (obligatorio)
- Colores: #FF4B00 / #0D0E12 / #FF6A1A / #FFFFFF. Sin degradados/brillos/sombras.
- Tipografía: Poppins (títulos) + Inter (cuerpo).
- Logo: SVG maestro de `brand-core/` (fondo oscuro → `_Dark`). Nunca regenerar.
- Regla 80/20 en piezas con comida.
