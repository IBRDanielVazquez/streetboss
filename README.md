# StreetBoss

StreetBoss es una plataforma FoodTech de venta directa para restaurantes.

## Propuesta principal

- Menú digital premium.
- Pedidos directos por WhatsApp.
- Cero comisión por venta.
- Control directo del cliente.
- Independencia de marketplaces.

## Lo que StreetBoss NO es

- No es un marketplace.
- No es una plataforma de delivery.
- No es un punto de venta.
- No es un simple generador de códigos QR.

## Identidad y Activos de Marca

El proyecto contiene en la raíz los activos consolidados de diseño y contenido:
- **`brand-core/`**: Logotipos vectoriales SVG maestros y guías del sistema de identidad visual.
- **`brand-assets/`**: Calendario de contenido de 90 días (posts, reels, stories), plantillas y guías de exportación.
